How I work

I don’t write the code line by line. I set what has to be true, build the checks that prove it, and review and disposition the failures. In quality terms: validate the code, test the instructions, qualify the system. The discipline lives in the deterministic parts — registries, scoring, and verification — so the model only has to do the part it is actually good at. A human with the competence to catch the failure modes makes the final call.

1. Specify

Named rules and registries define what must be true before anything is generated.

2. Check

Deterministic verification — not vibes. If a claim can’t be checked against a source, it doesn’t ship.

3. Disposition

A qualified human reviews the flagged gaps and decides. The agent flags; it does not conclude.

The work

Procedure generation

The Procedure Machine

Turns public FDA and ICH guidance into draft SOPs and test methods. Source material is fetched and assembled into a fixed packet first; drafting works only from that packet, pauses for a human where the guidance runs out, and finishes with an independent cold-read audit. Two modes: from your documents, or from public regulations.

Proof of concept

Fictitious Labs Inc. — EDMS

The Procedure Machine, pointed at a blank slate: a complete 44-document quality system for a fictional biologics company, generated from ICH, FDA, and CFR sources and adopted into a working document-control system — complete with a superseded method revision, because version traps are where reviewers earn their pay. A framework and a head start, not drop-in controlled documents.

Adversarial audit

The Stranger

A cold-read audit agent. It receives a finished draft — a deviation, a report, a procedure — with none of the drafter’s context or intentions, and reads it the way a skeptical reviewer would: looking for the gap, the unsupported claim, and the sentence that argues with another section. The human dispositions every finding.

Framework

Semantic Primitives

The design vocabulary behind the agents above: a registry of named, reusable primitives for governing AI agents in regulated environments — the root words from which constrained instruction sets are built, so expert reasoning survives being compressed into an agent’s instruction limit.

Training simulation

QC Lab Sim — A280

A text-based training simulation of a UV-Vis protein concentration assay in a QC lab. A deterministic core owns the event log — what actually happened, in order — so the debrief can be audited against the record instead of against a model’s memory of the session.

Review training

QA Review Simulator

Review training against the Fictitious Labs library: completed records with planted documentation discrepancies — transcription errors, wrong-version traps, bad corrections — scored deterministically. Flagging compliant entries costs points too, because that’s a failure mode in real review as well.
